Telegram bot

Requests arrive on Telegram with buttons to approve or reject them. Use a bot dedicated to this portal: if another program reads the same bot (Home Assistant, n8n…), the buttons stop working.

  1. In Telegram open @BotFather and send /newbot.
  2. Choose a display name, then a username ending in “bot”.
  3. BotFather answers with a token like 123456789:AA…: paste it here.
