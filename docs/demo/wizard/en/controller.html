Guest portal setup

Step 1 of 7

UniFi controller

The UniFi Network controller that manages the guest Wi-Fi, and a local account the portal uses to approve guests.

  1. In UniFi open Settings › Admins & Users (on UniFi OS: Control Plane › Admins & Users) and add an admin for the portal.
  2. Make it a local account (not a UI.com account), without two-factor authentication, with a role that can manage the Network application (Site Admin is enough).

For example https://192.168.1.10:8443 for a self-hosted Network Application, or https://192.168.1.1 for a UniFi OS console (UDM, UCG, Cloud Key). A self-signed certificate is fine.
