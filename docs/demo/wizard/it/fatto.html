Configurazione del portale

Salvato

La configurazione è salvata e il portale è attivo: gli ospiti possono già chiedere l’accesso. Puoi chiudere questa pagina.

Per cambiare la configurazione più avanti, crea il file /data/setup nel container e riavvialo: docker exec <container> touch /data/setup, poi docker restart <container>.
