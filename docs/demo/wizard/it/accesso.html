Configurazione del portale

Inserisci il codice di configurazione

Perché solo tu possa configurare il portale, il container ha scritto nel suo log un codice da usare una volta sola.

  1. Esegui docker logs <container> (con Docker Compose: docker compose logs).
  2. Copia il codice dalla riga “Setup code”.
