Controller UniFi

Il controller UniFi Network che gestisce la Wi-Fi ospiti, e un account locale che il portale usa per approvare gli ospiti.

  1. In UniFi apri Settings › Admins & Users (su UniFi OS: Control Plane › Admins & Users) e aggiungi un amministratore per il portale.
  2. Deve essere un account locale (non un account UI.com), senza autenticazione a due fattori, con un ruolo che gestisce l’applicazione Network (basta Site Admin).

Un gateway o una console UniFi OS (UCG Fiber, UCG Ultra, UDM, Cloud Key) risponde sulla porta 443: https://192.168.1.1. UniFi OS Server usa la porta 11443: https://192.168.1.10:11443. Una Network Application installata a parte usa la 8443: https://192.168.1.10:8443. Il certificato autofirmato va bene.
